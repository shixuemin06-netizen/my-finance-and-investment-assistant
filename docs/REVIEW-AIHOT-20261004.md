## 对照后的判断

| 对照项 | AIHOT 的可参考机制 | 本项目处理与验收 |
| --- | --- | --- |
| 页面信息层级 | 阅读入口、事件单位和日报分工 | 公开首页改为材料线索优先，条件判断单独展开；补资料覆盖、日报入口、来源说明和清晰的主次栏。保持已有绿色品牌，统一本地与公开版标题、字号和间距 |
| 时效 | 旧材料按原始发布日期归档 | 用最近收录时间判断过期，页面重打包不会刷新资讯年龄；日期缺失或未来收录时间显示待核；本期标题不再让历史材料看似今日新闻 |
| 生成依据 | 有原文、结构化出处与提示版本 | 本地首页判断现在同时复核正文、摘要一致性、原文指纹、真实引用和明确条件；旧依据改变或缺少条件时不进入首页判断 |
| 来源与模型 | 一手来源优先，摘要和原文分开 | 搜索的原文摘录与模型摘要保持不同标签；事件的概括明确标为模型摘要；展开条件时同时保留反证，不再二选一 |
| 事件独立性 | 来源去重、人工归属保留 | 继续保守归并，不以主题相近自动合并；首页明确来源独立性待核。报道数量不能作为证据强度或市场方向 |
| 可重复发布 | 共用公开读取层 | 保留公开字段允许清单、只读导出、固定数据库哈希、空目录输出、旧网址兼容和逐文件校验；固定名称的脚本、样式和资料索引改为重新验证缓存，避免新页面配旧资料 |
| 运行可靠性 | 独立后台、预算保护、失败恢复和付费回执 | 当前唯一 worker、预算、限流和恢复分支已有隔离测试。没有为对标而切换技术栈、模型或费用；真实供应商健康和连续运行仍需另行观测 |
| 校准 | 人工样本集和留出集 | 不移植 AI 资讯的双评分阈值与热度公式。现有回归用例只证明特定行为；尚没有财经精选的人工留出集，不报告整体判断准确率 |

两次评分可以降低部分随机波动，但相同模型、提示和材料造成的系统性错误可能重复出现；这不等于两个独立证据来源。财经排序需要关注变化范围、传导条件和原始依据，而不是讨论量。
