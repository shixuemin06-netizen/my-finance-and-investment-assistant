## 本轮已完成与未完成

本轮完成上述官方条款核验和风险清单，未取得媒体书面授权，未将“来源权威”视为商用许可。质量检测合格与权利核验通过属于两项独立条件；正文正确的转载仍可能需要授权。公开站保留原始链接和来源标签，不应把模型翻译称为官方中文版本。

尚需逐材料确认：原始权利人、授权证明与范围、标题/摘要/必要短引是否适用许可或法律例外、模型推理处理与训练是否分别允许、数据库/API 再分发权限、图片/商标权利、授权到期和撤回机制。此清单不是已完成的法律合规认证。

## 下一阶段建议

增加来源权利台账，记录 permission_status（verified / restricted / unknown）、条款链接与核验日期、允许的显示层（metadata / excerpt / summary / fulltext）、是否允许翻译和模型处理、凭证、到期日及原始权利人。公开构建读取经过核验的权限；未确认权利的材料进入审核，原始档案和私有研究不因此删除。当前公开网页的发布时间、收录时间及快照生成时间应继续分开，不把官方 RSS 当成实时或商业服务保障。

收费优先验证“事件持续跟踪、判断修正与证据积累”的价值。官方免费信息不得包装为独家内容；按需要取得专业媒体/数据库许可，再扩展覆盖面。正式商用前由负责法律审查的人核对地区、产品形态和具体展示方式。
