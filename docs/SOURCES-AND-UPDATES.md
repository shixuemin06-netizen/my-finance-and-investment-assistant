## 自动更新与预算
通过启动器启动一个独立后台进程，命名管道保证同一项目只能有一个 worker；数据库任务锁隔离手动与自动任务。
运行期间每小时检查一次；重启或休眠恢复仅补一次，不补跑全部错过时段。失败尝试同样按小时限频。
电脑关闭或本地服务退出后不继续更新。启动器会检查本项目健康标识，避免接管其他项目。
“最近检查”是采集任务结束时间；“内容更新”是有材料入库的时间，两者分别显示。
新材料先处理，每批最多 5 篇，每次最多 40 篇；只自动处理近七日入库且非已知旧发布日期的材料，不自动付费重做旧档案。
沿用 .env.local 的模型与预算；默认每日 1 元和原有请求上限。认证失败、限流或预算不足停止本轮模型处理，原文与已有摘要保留。未知失败请求保守保留预算预占。
来源失败逐个隔离；摘要不完整的任务标记 partial。
配置和密钥不进入前端、导出笔记或文档。源码中只预留单人上下文、权限能力和已有模型用量接口。

## 参考边界
Folo 用于学习连续阅读结构；NewsNow 用于学习来源适配与缓存状态；Ghostfolio 用于学习阅读工作区与管理分层。
AIHOT 用于观察精选、事件与日报组织，不接入其数据用于本产品。商业使用相关数据需要其书面授权；公开接口本身不构成商业使用许可。

### 2026-09-23 模型切换
本地摘要模型已配置为 `glm-5.3-flash`，使用智谱通用 API。密钥只保存在被 Git 忽略的 `.env.local`。该密钥的模型列表包含 GLM-5.3-Flash。用户授权前，仅使用虚构材料和独立临时 SQLite 验证完整摘要调用；授权后真实材料的验证结果见下。
官方[GLM-5.3-Flash 使用说明](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)说明思考模式需要保持启用。程序不再为 5.3 系列传入关闭思考参数，并将这类请求的超时阈值设为 120 秒。首页和后台继续保留已保存原文。
本地预算估算对 Flash 采用保守的每百万输入/输出 token 分别 ¥2/¥6，**不是服务商报价**；真实费用以智谱账单为准。每日 ¥1、200 次请求的现有设置未提高。官方编程套餐有积分和时间窗口额度，通用 API 与编程套餐的端点不同；不能把付费或模型列表可见理解为无限调用。
自动审批最初拒绝将真实本地文章正文发送到外部服务，因为当时尚无对该外传范围的明确授权。用户随后在 2026-09-23 明确授权公开采集及手动导入的财经材料发送至智谱 `glm-5.3-flash` 生成摘要和判断；本地已设置 `LLM_REAL_CONTENT_ENABLED=1` 并重启服务。

### 2026-09-23 启用后的实测
用户明确授权后，`glm-5.3-flash` 已对一篇人民银行公告和一篇 AI 产业报道生成并保存摘要、判断；判断引句逐字来自保存原文。模型对第一篇短公告曾因 2400 输出 token 被思考过程耗尽而未保存摘要，原文保持可读并按失败冷却，随后将上限调至 4096。冷却自然结束后，该公告以优化后的配置补验成功，约 25 秒完成。Flash 模型继续开启思考，但将推理强度调低：虚构材料完整摘要约 5.6 秒，真实 AI 产业报道约 18.6 秒。实际延迟和费用随材料、服务负载变化，不据此保证固定速度。
模型曾为一篇中文原标题返回重复的 `titleZh`；保存规则已改为只给英文原题且生成中文标题的材料存机器翻译，并清除了该条误标，不制造新的事件未读进展。模型用量仍受原有本地每日预算和请求上限约束。
