# 财经观点台账 · 产品与页面地图

## 本地阅读流程
今日总览发现变化 → 事件页区分来源陈述与模型解读 → 文章阅读核对原始依据 → 关注 / 收藏 / 笔记 → 我的研究查看后续更新。
首次访问无需问卷。没有新内容时展示实际历史日期；不虚构今日精选。

## 内容判断边界
事件的重要性排序目前是透明的规则编排：官方一手宏观发布优先，中国最多占三个优先位置，全球重大变化保留位置，优先近十四日材料，并按来源、地区和标题分散；无近期材料时保留历史日期。不是经用户验证的“经济影响评分”。
事件归类是可审计关键词规则，可能漏分。关联仅依赖规范化原始链接或能明确识别的同次央行政策日期；同一主题不会自动合并。不确定的关联保留独立材料，避免把不同统计月份或会议揉成一个事件。
相关报道数量只表示材料数量，不代表独立证据数量。模型摘要、传导判断与个人笔记分开；模型内容需回原文核对。

## 数据与兼容
新增 Story、StoryArticle、StoryUpdate、StoryState 及翻译、调度、活动表。原有日报 events / claims 保留日期语义；不重新解释历史数据。
原文、旧文章收藏与笔记无损保留。取消收藏不会删除笔记。
阅读进度保存看到的事件版本；后续追加报道或摘要更新会成为新进展。
笔记仅存于本地 SQLite，不进入模型请求。导出为 Markdown。
页面查询不在读取时重建索引；索引在迁移、导入及更新任务中增量维护。
改造前源码与在线 SQLite 备份：outputs/product-rebuild-20260922/before/。

## 使用验证
实际任务：读懂一件变化 → 找到原始依据 → 完成一次关注与笔记 → 下一次访问检查新进展。
product_activity 仅在本机记录每日访问、关注、保存、记笔记和阅读进度动作，用于观察回访与持续跟踪使用。没有第三方埋点。
目前不能据此宣称产品已有付费需求；需要后续真实用户验证。
