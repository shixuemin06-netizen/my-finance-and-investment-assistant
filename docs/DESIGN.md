# 统一视觉规范

设计基准来自 12ui 四个真实候选 A–D，选定 C。C 的中文无衬线层级、浅色侧栏、事件分隔线与独立全球侧栏适合连续阅读；A/B 的口号与装饰比重较高，D 过于依赖内容缩略图。
基准调整：压缩顶部标题区，移除无信息价值的装饰图；不使用设计示例中的虚构新闻、数量和账号状态。

- 背景：浅灰白；阅读面：白色；强调：低饱和青绿。
- 桌面侧栏约 216px；正文列最大约 720px；宽屏增加辅助栏。
- 正文 16px、行高 1.7；来源与状态至少 12px。
- 主要依靠留白、细分隔线与字重建立层级，避免叠套卡片。
- 链接、按钮、筛选、选中标签、焦点环统一。
- 768px 以下单栏、底部五项导航；日报和管理进入“更多”。
- 所有空状态提供可操作的下一步；失败保留已有内容或输入。
- 真实日期与状态优先，历史内容不使用“今日”标签冒充新鲜内容。

全局样式统一入口 app/globals.css；不再叠加导入 desk.css。
设计候选与当时验收属于历史记录，旧产物仍位于 _archive/outputs-history/product-rebuild-20260922/。
